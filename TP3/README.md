# Trabajo Práctico — HTML y CSS

Resolución de los 20 ejercicios solicitados.

## Estructura
Cada ejercicio está separado en su propia carpeta:
- `ejercicio-01` a `ejercicio-20`
- Cada carpeta contiene `index.html` y `styles.css`.

## Fuentes
Se tomó como referencia la documentación oficial de MDN:
- HTML: https://developer.mozilla.org/en-US/docs/Web/HTML
- CSS: https://developer.mozilla.org/en-US/docs/Web/CSS

## Decisiones de diseño
- Se utilizó HTML5 semántico cuando corresponde.
- CSS separado del HTML.
- Se incorporaron Flexbox, Grid, variables CSS, media queries, pseudo-clases, pseudo-elementos, animaciones y validación nativa.
- Los ejercicios con imágenes usan imágenes de marcador de posición externas para que puedan reemplazarse fácilmente.
- El ejercicio 15 utiliza enfoque desktop-first y lo justifica mediante un comentario en CSS.
- El ejercicio 17 funciona sin JavaScript mediante checkbox + `:checked`.
- El ejercicio 19 utiliza `:target` para cambiar entre pasos.

## GitHub
Para entregar, crear un repositorio y subir esta carpeta. Luego se puede compartir la URL del repositorio.
